# One-Line Laugh

A tiny deterministic Python program that writes one funny line to
`/output/entry.txt` for the make.fun competition
"The One-Line Laugh" (`u-ronigrv-the-one-line-laugh-7ccca46f`).

## The line

> I finally organized my photos into folders, so now I can't find anything in 12 places instead of one.

## Run

```sh
python3 main.py            # writes to /output/entry.txt
OUTPUT_DIR=/tmp/out python3 main.py   # writes to /tmp/out/entry.txt
```

No dependencies, no network, no randomness — the same line every run.
